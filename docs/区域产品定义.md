# 马来西亚市场 · 区域产品定义（演示）

owner：`demo.metrics`  
version：`2026.08.2`  
给「海外产品定义 / 国际数据分析域」对齐用。数据是马来西亚公开 TIV 年锚 + 固定种子拆分的演示数据。

## 要解决的一线问题

区域销售问「谁卖得好」时，协会批发（TIV）和上牌经常对不上。先定口径，再谈份额和竞品。

## 口径（必须先选）

| 指标 | 用在哪 | 不要当成 |
|------|--------|----------|
| TIV / 批发 | 协会风格出货 | 上牌、零售成交 |
| 上牌 / 注册量 | JPJ 风格演示列 | TIV |
| 国产车 | 仅 Perodua + Proton | 「马来西亚生产的都算」 |

年锚（公开报道 TIV-style）：2025 年合计 **820,752**；Perodua **359,904**。  
月 × 区域 × 车型是种子拆分，面试时要主动说。

## 竞品结构（演示观察，不是投放建议）

- 国产双强：Perodua、Proton（origin = national）。
- 非国产里公开年锚含 Honda、Toyota、Mazda、BYD；Chery / Others 是演示残差，不当协会官方行。
- 库里没有 Geely 品牌行。问「吉利在马来西亚销量」必须停。

## 用户场景（可问）

1. 2025 全年协会口径谁第一  
2. 某品牌 TIV 份额 / 同比  
3. 巴生谷 / 柔佛等区域排名  
4. TIV 和上牌有什么区别、数从哪张表来  

不可问：华南、豪华车无定义、相对时间、2026 年。

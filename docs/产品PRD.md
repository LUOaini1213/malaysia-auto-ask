# PRD · 马来西亚汽车海外一线工作台（演示）

版本：2026.08.2  
验收：本机 `python scripts/serve.py` 打开 `/desk`。不是上线业务。

## 背景

海外销售 / 售后要数，但 TIV 和上牌两套口径。问不清就给数，一线会拿错去对客。

## 用户

区域销售、售后、产品定义（演示角色）。英语可对照页面上的口径英文名（TIV / registration）。

## 用户路径

```
进 /desk
  → 看年锚卡片（TIV 合计、第一名、国产口径）
  → 输入问句
      ├ 口径不清 / 库外  → 停，写原因，不起草
      ├ 问口径 / 血缘    → 检索片段 + 表级路径
      └ 问数            → 白名单 SQL 出表 + 口径 + 血缘
  → 「给一线的说明草稿」
      → 人勾选确认 → 才能复制
      → 未确认：复制键不可用
```

系统不发邮件、不外呼、不写成交率。

## 功能

| 编号 | 功能 | 验收 |
|------|------|------|
| F1 | 看板卡片 | 2025 TIV 年锚与第一名品牌能出数 |
| F2 | 问数 | 规则解析（正则 + 词典）+ 白名单 SQL；任何上游解析器都不拼 SQL |
| F3 | 口径检索 | TIV vs 上牌走词重叠，无向量库 |
| F4 | 说明草稿 | 带口径、结果、血缘；HITL 才能复制 |
| F5 | 停问 | 「谁卖得最好」无草稿 |

## 非目标

智能外呼、话术助手、智能客服、RoboOS、座舱语音、厂商内部问数、SPSS/Figma。

# 口径

owner：`demo.metrics`  
version：`2026.08.1`（指标） / `2026.08.2`（分层与血缘）

不是 MAA/JPJ 原始数，不是吉利问数，不是企业 Atlas，不是向量 RAG。

## tiv

协会风格批发（TIV-style）。  
问句里出现 TIV / 批发 / 协会口径才用。  
「销量」「卖得好」单独出现 → HITL，不默认。

## registration

上牌。与 TIV 分列存储，同月同车型可以不一致（演示：巴生谷上牌偏高、东马上牌偏低、12 月批发赶工）。

## share

分子分母必须同一指标、同一时间、同一区域筛选。默认用当前选中的 tiv 或 registration。

## national

仅 `dim_brand.origin = national`（Perodua、Proton）。  
「非国产」不是「进口」的同义词，只是 origin 另一档。

## 分层

演示数仓，四层可查。不是企业数仓平台。

| 层 | 对象 | 说明 |
|----|------|------|
| ODS | `ods_brand_year_anchor` | 公开报道的品牌年 TIV 锚 |
| DIM | `dim_brand` / `dim_model` / `dim_region` | 品牌、车型、区域 |
| DWD | `fact_month` | 年-月-车型-区域；`tiv_units` 与 `registration_units` 分列 |
| ADS | `ads_brand_year` / `ads_brand_month` | 品牌年 / 品牌月汇总 |

全年、无区域、无能源筛选的品牌合计走 ADS；带月 / 区域 / 能源 / 车型走 DWD。  
月×区×车型是固定种子拆分，不是协会原始明细。

## 血缘

问「数从哪来 / 哪张表 / 溯源」返回表级路径。不扫列级，没有外部血缘系统。

- TIV ← `fact_month.tiv_units` ← `ods_brand_year_anchor`（年锚）  
- 上牌 ← `fact_month.registration_units`（演示列，允许与 TIV 不一致）  
- 全年品牌合计还可 ← `ads_brand_year`

口径问句检索本文和 `metric_dict`，词重叠，无向量库。

## 不在库里的

吉利品牌行、中国大区、2026 年、豪华车定义。问到就停。
